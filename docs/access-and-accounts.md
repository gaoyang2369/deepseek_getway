# 访问方式与学生账号

## IP、HTTPS 与校园网

当前模拟入口为 `http://10.108.13.250:18081`，监听 `0.0.0.0:18081`。`0.0.0.0` 表示接收各 IPv4 网卡的连接，不会为校园网服务器分配公网 IP，也不会改变上游网络的路由或防火墙。浏览器使用实际服务器 IP。

IP＋端口可以提供服务；域名不是应用的技术必需条件。HTTP 不加密传输的登录密码、会话和 Bearer API Key，正式成员接入应使用 HTTPS 等受保护的传输。HTTPS 和网络可达是两个独立问题，给 `10.108.13.250` 绑定域名不等于能从校外访问。[OWASP 认证传输建议](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html#transmit-passwords-only-over-tls-or-other-strong-transport)。

IP 也可以使用 TLS 证书。私网 IP 可通过校内 CA 或自管 CA 签发，但浏览器与 SDK 需正确信任该 CA；不要通过关闭证书校验来长期使用。域名通常使统一入口与证书管理更方便。[Caddy 关于 IP 和内部 HTTPS 的说明](https://caddyserver.com/docs/automatic-https#local-https)。当前应用生产校验要求 `PUBLIC_URL` 使用 HTTPS，不要求一定是域名；现有 HTTPS 代理模板尚未安装，不影响当前 HTTP 模拟测试。

## 校外成员如何使用

| 方案 | 网关位置 | 成员需要做什么 | 主要条件 |
| --- | --- | --- | --- |
| 学校提供的校园 VPN | 当前校园服务器 | 接入 VPN 后访问网关 | VPN 必须能路由到服务器的 TCP 18081；仅代理网页的 WebVPN 未必支持 SDK |
| 经允许的专用组网，例如 Tailscale | 当前校园服务器 | 服务器和客户端加入受控网络 | 学校与成员设备允许安装，配置成员访问权限；网络连通性需实测 |
| 将整套网关部署到公网云服务器 | 云服务器 | 访问统一公网 HTTPS 入口 | 云服务器、受控管理入口、证书与维护；仍由个人网关 Key 统一计量 |
| 云端入口＋校园服务器主动建立加密隧道 | 仍在校园；云端反向代理 | 访问云端统一入口 | 学校允许对外建隧道，按权限发布网关服务；仍依赖校园服务器在线 |

Tailscale 支持不同网络中的成员访问授权的开发服务器：[官方说明](https://tailscale.com/docs/concepts/local-team-server)。Cloudflare Tunnel 是另一类主动向外建立连接的入口实现，无需校园服务器具有公网 IP：[官方说明](https://developers.cloudflare.com/tunnel/)。这些方案均未在当前服务器安装，也未验证实际校园网络与校外设备的连通性；部署前选择学校允许、实际可用的方式，不绕过网络管理限制。

测试阶段优先确认学校是否已有可用的客户端 VPN。若长期希望成员无需额外 VPN 客户端，部署公网云网关通常更直接；也可保留校园主服务而仅部署云端中转。校外调用 API 时仍需持续保持到网关的网络可达，并非第一次网页登录领取 Key 后即可离线访问网关。

单独发放“网关个人 Key”不能解决网络不通；若改为给每个人直接发官方 Key，学生可以绕过本网关调用官方 API，但也绕开了本项目统一预算、审计与服务端路由。

## 学生使用流程

1. 管理员在“学生账号”页导入学号，可同时填写姓名，绑定项目组及预算。
2. 模拟阶段可用学号作为初始密码；正式环境使用随机临时密码并单独交付。只有学号＋学号无法证明操作者身份，首次强制改密不能防止他人抢先登录。
3. 学生在 `/student` 登录后先改密；后端拒绝未改密账号签发 Key。
4. 学生领取只显示一次的个人 Key，保存 API 接入地址及允许模型。浏览器会话到期不影响已经签发的 API Key。
5. 遗失 Key 时登录并轮换；遗忘密码时联系管理员核实身份并重置。重置撤销全部旧会话与该学生全部旧 Key，再次登录仍强制改密；预算记录不重置。

测试账号 `2026001001`、`2026001002`、`2026001003`，每人每月 10 元，初始密码为各自学号（已使用账号以修改后的密码为准）。所有价格、预算和上游均为模拟数据，未发送真实付费请求。

学生联系邮箱可由管理员在 `.env` 中填写 `SUPPORT_EMAIL` 后重建网关容器。当前未提供该邮箱，页面显示联系管理员提示；系统不自动发邮件。

## 官方凭证

聊天中出现的官方 Key 建议在官方平台作废换新。新的服务器专用 Key 通过受保护的管理页面录入组凭证，不再粘贴到聊天，不写入源码、文档或前端。当前部署仍连接模拟上游；真实供应商接入、模型及价格核验、账单比较尚未执行。
